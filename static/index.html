Callback Checklist

A post-discharge callback built as a finite-state checklist, not a chatbot. The discharge summary is compiled once into 5 to 8 fixed questions. A simulated patient answers; a small local grammar fills the answer slots; a red-flag answer or two answers the machine cannot understand creates one escalation task for a human. Simulated calls only: no telephone network is connected in this demo. Real telephony is a documented integration, not part of v0.1.0.

What it never does: it never interprets an answer into a diagnosis, never gives treatment advice, and never claims to reduce readmissions. The evidence for a single automated contact doing that is not there (see EVIDENCE.md in the repo). It asks, it records, it escalates.

Press the button to run a simulated call.
